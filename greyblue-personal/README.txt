GREYBLUE — PRIVATE PERSONAL BUILD

This bundle is for Katherine's local use. It does not publish or deploy anything.

Start:
  Double-click "Start Greyblue.vbs".

What it does:
  - starts a local HTTP server bound only to 127.0.0.1
  - opens Greyblue in the default browser
  - serves the bundled Greyblue source, dragon models, and vendored Three.js files
  - shuts the local server down automatically after eight hours

Requirement:
  Node.js 22 or newer must be installed on the computer.

The build manifest records the source commit and bundled Three.js version.
